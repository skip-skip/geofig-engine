# Phase 17: IO / Data subpackage (`geofig_engine.io`)

**Status**: complete
**Phase**: 17
**Version target**: v0.3.0
**Dependencies**: none (phase overview)

## Description

Port and generalize geochemplot's data-handling utilities into a dedicated
`geofig_engine.io` subpackage (ROADMAP Phase 17). Part of the package already
shipped in earlier phases; this epic tracks the remaining scope and the
phase-level contract.

**Already shipped (Phase 14, `de36ea1`, tested in `tests/test_io.py`):**

- `io/geo.py` — `haversine()` (great-circle distance, km), `path_distance()`
  (cumulative or per-segment along an ordered point path)
- `io/markers.py` — `gen_markers()`, `gen_markers_series()`,
  `gen_markers_cross_grouping()` (itertools.product over marker list + color
  palette; also resolves the ROADMAP Backlog "Marker/color combinatorial
  generator" item)
- `io/preprocess.py` — `Pipeline` / `PipelineStep` chained frame transforms
  (also covers the Phase 18 "data preprocessing pipeline" item)

**Shipped in this phase (wp1–wp3, see `tasks/closed/17_wp*_*.md`):**

1. **EQuIS format conversion** — `equisflat_to_sample_df()` (pivot flat to
   wide), `sample_df_to_equisflat()` (melt wide to flat), and
   `equis_crosstab_to_flat()` (parse EQuIS cross-tab Excel) — `io/equis.py`.
2. **Unit utilities** — `equisflat_normalize_units()` (normalize SI prefixes
   nano→kilo within analyte groups) — `io/units.py`.
3. **Column utilities** — `ecesis_to_sample_df()` (parse Ecesis-style column
   names with embedded units), `create_bins()` (categorical bins from numeric
   or datetime columns, range or quantile) — `io/columns.py`.

**Explicitly out of scope:** mg/L → meq/L conversion (deferred to an external
data system per the ROADMAP note); carbonate speciation (computing HCO3+CO3
from alkalinity + pH + temperature) is handled by a separate modeling module,
not `geofig_engine.io`.

## Phase-level acceptance criteria

- [ ] `geofig_engine.io` exports every utility from the three remaining WPs
      plus the already-shipped geo/markers/preprocess set (public exports)
- [ ] Each conversion is deterministic, pure-pandas (no new required
      dependencies), and never mutates its input frames
- [ ] Contracts are documented in module/function docstrings; malformed input
      raises `ValueError` with an informative message
- [ ] Excel file reading is gated behind `pytest.importorskip("openpyxl")` in
      tests; the engine adds no hard dependency
- [ ] Full suite green (baseline 1332 passed / 6 skipped) after every WP
- [ ] Commits labeled `geofig-engine: <scope> → v0.3.0`
